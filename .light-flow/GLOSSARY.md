# GLOSSARY

Однострочные коды для повторяющихся терминов. Определено один раз, дальше —
код. Ссылки на код не сокращаются.

## Ядро платформы

- `Platform` — корень платформы: реестр игр, глобальные настройки, создание сессий.
- `Game` — базовый класс игры: правила, очередь хода, рендер, сериализация.
- `Session` — контроллер партии: игроки, очередь, жизненный цикл, снимок.
- `Player` — игрок: `id`, `name`, `agent` (human/computer), `transport` (local/remote), игровые свойства.
- `Viewport` — canvas-компонент: камера, зум, панорама, dpr, отсечение.
- `DialogManager` — один `<dialog>` и стек экранов с «назад».
- `Palette` — тема: `prefers-color-scheme`, токены OKLCH, системный акцент.
- `KeyValueStore`/`Storage` — асинхронное хранилище ключ-значение.
- `GameSaves` — модуль сохранений партий, узлы `game/<id>`.
- `Transport` — канал: `LocalTransport` / WebRTC.
- `NetLink` — мост «сессия ↔ сеть» (send/hello/sync).
- `Lobby`/`LobbyRoster` — сетевое лобби и ведомый хостом состав.

## Понятия

- `isDemo` — сессия-демо (фон): не сохраняется, слои UI не монтируются.
- `playerId` — постоянный UUID игрока (генерация при первом запуске).
- `guest_N` — временный id локального игрока (кроме главного).
- `sync` — сообщение протокола: хост шлёт гостю снимок состояния.
- `adoptState` — приём гостём состояния от хоста при восстановлении.
- `D*` — принятое решение в `CONTEXT.md`.
- `T*`/`R*` — задача плана (`T` — базовая, `R` — доработка 12-b).
- `Проверка` — маркер проверенной фазы в `REPORT.md` (читает роутер).
- `BACKLOG` — корневой список задач/исследований, переживает спринты.
