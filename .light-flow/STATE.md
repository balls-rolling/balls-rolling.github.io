  paste для кодов приглашений (портировано из `js/app.js:15-18`).
- **Диалоги, проверено по MDN и BCD:** `showModal()` делает вне диалога `inert`
  (клики, фокус, всё), Esc закрывает только верхний модальный диалог — ручная
  блокировка не нужна. `closedby` по умолчанию для `showModal()` = `closerequest`
  (то есть Esc закрывает), поэтому атрибут ставится **явно всегда**. Поддержка
  `closedby`: Chrome 134, Firefox 141, Safari preview — потому нужен второй
  барьер, перехват `cancel`. Для отменяемых закрытий — `requestClose()`, а не
  `close()`. Есть Invoker Commands API (`command="show-modal" commandfor=...`),
  годный для универсальной кнопки. Анимация требует `@starting-style` +
  `allow-discrete` + `display` и `overlay` в transition; `::backdrop` закрытие
  не анимируется. Подробности — в `PROJECT.md` и `BACKLOG.md`.
