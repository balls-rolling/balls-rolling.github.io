## T5. Палитра: системная тема и системный акцент

**tests: n** · зависит от: T2 · **параллельно: T4**

**Файлы:** `src/core/theme/palette.ts` (новый), `src/core/theme/index.ts`
(новый, реэкспорт), `src/main.ts` (точечная правка — вызов палитры **до**
монтирования, иначе первый кадр успеет отрисоваться со светлой темой на тёмной ОС).

**Почему так:** палитра ложится в `core/` — это поведение и данные (D2), а
`styles/` по D1 — токены; палитра заполняет их в рантайме. Реакция на смену темы
ОС обязана быть в рантайме, а не через `@media` в CSS, потому что нужно
выставлять атрибут и JS-переменную `--accent`.

**Переносим** из `js/theme/palette.js`: `FALLBACK_ACCENT = "#3da96a"`,
`readSystemAccent()` со скрытым пробником `color: AccentColor` и фильтром мусора
(`rgb(0, 0, 0)`, `canvastext`), `applyPalette()` — ставит `documentElement.dataset.theme`
и CSS-переменные, `watchPalette()` — вызов + подписка на
`matchMedia("(prefers-color-scheme: dark)")`.
**Упрощается одно:** `oppositeMuted()` в исходнике — заглушка, возвращающая
`accent` без побочных эффектов (комментарий описывает идею, а не реализацию),
поэтому функция не переносится.

**Done-condition:**
1. `npm run typecheck` и `npm run build` — код 0.
2. **В браузере:** при системной тёмной теме `documentElement.dataset.theme === "dark"`,
   при светлой — `"light"`; смена темы ОС на лету меняет атрибут без перезагрузки
   (DevTools → Rendering → Emulate prefers-color-scheme).
3. **В браузере:** `getComputedStyle(document.documentElement).getPropertyValue("--accent")`
   непустая и не равна чёрному / `canvastext`; фолбэк `#3da96a` при недоступности.
4. В `src/core/` нет ни одного упоминания конкретной игры (grep) — ядро не знает
   ни одной игры (D2).
5. Исходник `C:\projects\light-flow\tic-tac\js\theme\palette.js` не изменён.

**Механизм:** `import.meta.glob("../../games/*/index.ts", { eager: true, import: "default" })`.

и `import`. Типизация требует `"types": ["vite/client"]` в `tsconfig.json`
(учтено в T2), иначе `vue-tsc` не примет запись. На фазе 01 фиксируется
**формат реестра**, а не поведение — контракт `Game` это фаза 02.

**Done-condition:**
1. `npm run typecheck` и `npm run build` — код 0; сборка не падает на пустом
   `games/` (glob не провисает на отсутствии совпадений — проверяется этим билдом).
2. **В браузере:** панель показывает `0 игр`, ошибок в консоли нет.
3. **В браузере:** временно создать `src/games/probe/index.ts` с экспортом
   `{ id: "probe", label: "Проба" }`, перезапустить dev — панель показывает `1 игр`
   и лейбл «Проба»; файл удалить, панель снова `0`. Это подтверждает, что
   механизм рабочий, а не «работает потому что пусто».
4. Grep по `src/core/`: ни одного упоминания `probe`, `tic-tac-toe`, `billiards` —
   ядро не знает ни одной конкретной игры (D2).
5. В `src/` существуют ровно четыре слоя `core/`, `ui/`, `games/`, `styles/` (D1).
