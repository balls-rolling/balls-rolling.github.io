## Порядок и параллельность

T6 ─▶ T7 ─┘   │   │       │

## Швы, которые надо знать исполнителю

- **Токены → примитивы → компоненты.** T1 объявляет имена, T2 использует их в
  примитивах, T3/T4 переводят на примитивы существующие компоненты. Правка
  компонентов до T2 бессмысленна.
- **Тема в ядре (T6) и в UI (T8) разведены.** T6 не знает Vue; T8 только грузит
  режим в форму и сохраняет. Тема применяется до первого кадра (T7) — не в
  компоненте.

## Решения

- **Токены** — собственные, по конвенции HIG/M3/Fluent как ориентиру, без
  «токенов M3». Цена: 0 зависимостей, полный контроль; стоимость — сопровождать
  свой CSS.
- **Примитивы** — свои CSS-классы, не библиотека (D7). Цена: 0 зависимостей.
- **Иконки — библиотека `@lucide/vue@1.51.0` (ISC), реестр «токен → компонент».**
  Выбор пользователя: инлайн SVG отвергнут по виду. `lucide-vue-next` устарел —
  берём `@lucide/vue`. Цена: +1 runtime-зависимость, ~0.5 КБ на используемую
  иконку при явных импортах; tree-shaking сохраняется только при явных импортах
  (динамический `import *` запрещаем). Отклонены: `unplugin-icons`+
  `@iconify-json/lucide` (совместимость с Vite 8 официально не подтверждена),
  `@iconify/vue` (грузит данные из сети в рантайме), `@heroicons/vue` (узкий набор,
  редкие релизы).
- **Тема** — хранить режим `system|light|dark` (default `system`), в DOM писать
  разрешённое значение; `[data-theme]` работает как есть, `color-scheme`
  привязывается к разрешённой теме. Отклонены: User Preferences API
  (экспериментально), хранение хеша цвета (хрупко).
- **FOUC** — синхронный inline-скрипт в `<head>` (официальная рекомендация). Цена:
  дублирование парсинга конверта в HTML + `try/catch`; приемлемо.
- **Доступность переключателя** — нативный `<select>` с label, не `role="switch"`
  (три состояния бинарным switch не выражаются).
- **Хранение** — расширяем `GlobalSettings`; помним про две точки записи и полные
  сравнения в `platform.test.ts`.

## Риски

- FOUC/FART на медленном первом кадре; кросс-вкладочная синхронизация темы
  (`storage` event) — вне объёма.
- Потеря нового поля в двух точках записи и полные сравнения в `platform.test.ts` —
  закрываем тестами T6/T8.
- `color-scheme` против системного `AccentColor` и Chrome Auto Dark — только
  ручной прогон (T7/T9).
- `localStorage` может бросать — inline-скрипт в `try/catch`, тихий фолбэк на
  `system`.
- Визуальную часть автоматически не проверяем — регрессии ловим ручной матрицей T9.

## Проверка фазы

- `npm test` (в т.ч. новые тесты T6), `npm run typecheck`, `npm run build`,
  `npm run format`.
- Вручную в браузере: матрица тем × окон × фокуса; контраст; отсутствие FOUC.
- **Автотестами не проверяется:** композиция и внешний вид — только ручной прогон;
  в отчёте отметить явно.
