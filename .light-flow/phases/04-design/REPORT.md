## Отклонения от плана

1. **`src/ui/environment.ts` не менялся.** Он пишет `{...settings, lastGameId}`, то
   есть `themeMode` сохраняется спредом; отдельная правка не нужна. План T8
   перестраховывался.
2. **Иконки в шелле и экранах — прямыми импортами `@lucide/vue`**, не только через
   реестр. Реестр обслуживает `Control.icon` (ядро остаётся со строковым токеном);
   статичные иконки меню/назад/меню-кнопки импортируются явно (tree-shaking).
3. **Добавлены утилиты** `.list-reset`, `.text-muted`, `.icon` — понадобились при
   переводе компонентов; в плане названы не были.
4. **`meta[color-scheme]` обновляется inline-скриптом при загрузке**, но не при
   рантайм-переключении темы. Не критично (влияет на до-стилевую отрисовку), но
   отмечено.

### Панель колокольчика — нативный popover (третий заход)

- Панель переведена на `popover="auto"` + anchor positioning: кнопка —
  `anchor-name`, панель — `position-anchor` и `top: anchor(bottom)` /
  `right: anchor(right)`. Уникальные id и якорь через `useId()` (в DOM живут два
  колокольчика).
- Клик мимо и Esc закрывают панель **нативно** (light-dismiss), обработчиков нет.
  Проверено реальным кликом: клик по «Игры» закрыл панель и открыл экран; Esc
  закрыл.
- Анимация: `@starting-style` + `transition-behavior: allow-discrete` с `display`
  и `overlay` — появление выездом сбоку (`translateX(24px)`, `blur(6px)`), закрытие
  растворением (прозрачность + blur).
- Подводный камень: UA-стиль `[popover] { inset: 0 }`. Без явных `left/bottom:
  auto` переконстрейн перекрывал якорные `right/top`, и панель вставала в левый
  верхний угол. Найдено замером в браузере и исправлено.

Проверки: `typecheck`/`test` (93)/`build`/`format` — 0. Браузер: панель
открывается, привязана под кнопкой справа (`top` = низ кнопки + 8, `right` = 16),

### Горизонтальный скроллбар стека (пятый заход)

- Симптом: при выезде стека на миг появлялся горизонтальный скроллбар, панель
  дёргалась по высоте.
- Причина: UA-стиль `[popover] { overflow: auto }` плюс строки, выезжающие
  `translateX`, давали горизонтальный оверфлоу внутри панели.
- Исправление: панель — `overflow: hidden` (скроллится не она), список —
  `overflow-x: hidden; overflow-y: auto`; у контейнера тостов тоже `overflow:
  hidden`.
- Замер в браузере: панель `scrollWidth == clientWidth` (318), список
  `scrollWidth == clientWidth` (294), высота панели неизменна (172) в процессе
  анимации и после; консоль пуста.
- Уточнение: у строк стека **убран горизонтальный вход** (`translateX`) — панель
  выезжает целиком, строки лишь появляются/растворяются прозрачностью и blur.
  Итоговый замер: `scrollWidth == clientWidth` (294) и высота панели неизменна
  (174) и во время анимации, и после.
- Жёсткий `max-height: 320px` у списка убран. Панель ограничена высотой экрана с
  полями (`max-height: calc(100dvh - …)`), список — `flex: 1 1 auto; min-height: 0;
  overflow-y: auto`. Замер с 26 уведомлениями: панель 1127px (кэп), нижний зазор
  16px, верхний 72px, список скроллится (`scrollHeight` 1500 > `clientHeight` 1061);
  с 10 уведомлениями панель 638px, без скролла — жёсткого лимита нет.
