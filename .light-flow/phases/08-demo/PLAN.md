# PLAN — Фаза 08: фоновое демо

**Флаг тестов фазы:** y.

Живое демо за меню: случайная игра из реестра, ИИ vs ИИ, граница слоёв,
перезапуск после партии.

---

## Задачи

### T1. `Game.getDemoPlayers()`
**Файл:** `src/core/game/game.ts`.
Метод `getDemoPlayers(): readonly PlayerInit[] | null` → `null` по умолчанию.
Импорт `PlayerInit` из `../player`.
**tests:** y (no-op по умолчанию). **Зависит:** нет.

### T2. Демо крестиков-ноликов
**Файл:** `src/games/tic-tac/game.ts`.
`override getDemoPlayers()`: выставляет `this.level = 2`, `this.missWin = false`,
возвращает двух компьютеров (`ai-1`/`ai-2`, «Компьютер 1/2», `transport: "local"`).
**tests:** y. **Зависит:** T1.

### T3. `Platform.createDemoSession()`
**Файл:** `src/core/platform/platform.ts`.
Перебирает `listGames()` в случайном порядке, поднимает игру, берёт
`getDemoPlayers()`; на первой подходящей — `new Session({ game, players, options:
{ demo: true } })`. Возвращает `Promise<Session | null>`.
**tests:** y. **Зависит:** T1.

### T4. Запуск демо и перезапуск
**Файл:** `src/main.ts`.
На старте: если диалог ещё не открыт — `createDemoSession()`, кладём в
`sessionHost`, `start()`; подписка: партия завершилась → через ~1500 мс
`session.restart()`. Меню открывается поверх (как сейчас).
**tests:** n. **Зависит:** T3.

### T5. Граница слоёв
**Файл:** `src/App.vue`.
Инъекция `sessionHost`; слой игрового UI (`LayerGameUi` + `SessionHost`) монтируется,
только если активная сессия не демо (`!session?.isDemo`); слой диалогов — всегда.
**tests:** n. **Зависит:** нет.

### T6. Тесты
**Файлы:** `src/core/game/*.test.ts` (или в `platform.test.ts`),
`src/games/tic-tac/game.test.ts`.
`getDemoPlayers` по умолчанию `null`; крестики-нолики — 2 компьютера и настройка;
`createDemoSession` возвращает демо-сессию у игры с демо и `null`, если демо нет
(стаб-игры); `session.isDemo === true`.
**tests:** y. **Зависит:** T1, T2, T3.

### T7. Проверка фазы
`npm test`, `npm run typecheck`, `npm run build`; браузер: за меню идёт партия
ИИ vs ИИ (ходы появляются сами), нет баннера и кнопки меню на поле; после
окончания партия продолжается; запуск «Крестики-нолики» сменяет демо на реальную
игру.
**tests:** y. **Зависит:** T4, T5, T6.

## Решения

| # | Решение | Обоснование | Отвергнуто |
| --- | --- | --- | --- |
| 1 | Состав демо — `Game.getDemoPlayers()` | Игра решает способ демо (D1) | Платформа создаёт игроков |
| 2 | `Platform.createDemoSession()` | Выбор игры — дело платформы (D2) | Логика в `main.ts` |
| 3 | В демо нет слоя игрового UI, диалоги есть | Меню — диалог поверх демо (D3) | Прятать CSS |
| 4 | Перезапуск после партии | Живой фон (D4) | Замирание |
| 5 | Уровень 2, без `missWin` | Конечная партия (D5) | `missWin` обоим |
| 6 | Зависимостей нет | Нативные средства (D6) | — |
