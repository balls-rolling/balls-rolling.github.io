## Задачи

### T1. Кнопка «Двое за экраном»
**Файл:** `src/games/tic-tac/game.ts`.
В группе «Режим» формы преднастройки — вторая кнопка `hotseat` («Двое за экраном»,
иконка `users`). Группа остаётся вертикальной.
**tests:** y. **Зависит:** нет.

### T2. Запуск двух локальных людей
**Файл:** `src/games/tic-tac/game.ts`.
`#start` принимает состав (`humans`/`computers`); подписка на `hotseat` зовёт
`#start` c `{ humans: 2, computers: 0 }`; `vs-computer` — `{ humans: 1,
computers: 1 }`.
**tests:** y. **Зависит:** T1.

### T3. Тесты
**Файл:** `src/games/tic-tac/game.test.ts`.
Форма содержит `hotseat`; клик-обработчик не тестируем без DOM — проверяем состав
через `defaultPlayers` не здесь, а косвенно (в форме). Достаточно: `hotseat` есть
в форме; `vs-computer` остаётся.
**tests:** y. **Зависит:** T1.

### T4. Проверка фазы
`npm test`, `npm run typecheck`, `npm run build`; браузер: «Двое за экраном» →
сессия с двумя людьми; клики чередуют ход; баннер меняет имя; меню «Сдаться и
выйти».
**tests:** y. **Зависит:** T2, T3.
