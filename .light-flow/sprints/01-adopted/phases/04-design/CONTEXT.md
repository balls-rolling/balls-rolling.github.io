# CONTEXT — Фаза 04: Дизайн и вёрстка

## Что делает фаза

Приводит UI фазы 03 к единому современному адаптивному виду; меняется **только внешний вид**, единственное функциональное исключение — переключатель темы (D4). Готово: путь «меню → список игр → преднастройка → сессия», лобби и настройки аккуратны и адаптивны; светлая/тёмная тема и системный акцент сохранены; компоненты оформлены единообразно; малое окно не ломается.

## Принятые решения (D*)

- **D1. Строгий объём: только внешний вид.** Прямое требование роадмапа; пересмотр навигации меню не берётся (это UX/поведение, потянуло бы функциональность).
- **D2. Визуальный язык: база источника + современные гайды.** Основа — палитра/токены источника (`--bg-*`, `--card`, `--fg`, `--line`, `--accent`, `--radius*`, `--shadow` в `styles/tokens.css`), доводим по HIG/Material/Fluent (ориентиры уточняются ресёрчем на plan); главное действие — градиент `color-mix(in oklch, …)` с фиксированным тёмным текстом.
- **D3. Композиция: центрированная карточка, один столбец.** Ограничение по `max-width`, вертикальный поток, внутренний скролл на малом окне; адаптив по ширине/высоте (`dvh`, safe-area). Сеток/двух колонок нет.
- **D4. Переключатель темы (единственное функциональное исключение).** Системная/Светлая/Тёмная (default Системная), в глобальных настройках (localStorage рядом с именем), переживает перезагрузку; место — экран настроек.
- **D5. Общие UI-примитивы.** Оформление вынесено в набор примитивов (кнопка, поле, группа) и переиспользуется; реестры контроллов по `kind` и экранов остаются.
- **D6. Иконки: интерфейс объявлен, выбор — ресёрчем на plan.** `Control.icon` — строковый токен в ядре (Vue в ядро не протекает); библиотека в UI реестром «токен → компонент»; конкретный выбор/версии/лицензия не фиксировались до plan.
- **D7. Библиотеки компонентов и стилей не берём.** Дублируют нативные `<dialog>`/`<details>`, CSS-фреймворк ломает свою систему токенов/preflight.

## Отклонённые варианты

| Вариант | Почему отклонён |
| --- | --- |
| Пересмотр навигации меню | UX/поведение, противоречит «только вид» (D1) |
| Токены с нуля | Проверенная база источника уже есть (D2) |
| Сетки и две колонки | Нет контента, усложняет (D3) |
| Тема только из ОС | Выбран ручной переключатель (D4) |
| Локальные стили в компонентах | Дублирование и расхождения (D5) |
| Компонентная/CSS-библиотека | Дублирует нативное, ломает токены (D7) |

## Объём фазы

**Делаем:** доводку токенов/типографики; общие UI-примитивы; вёрстку экранов и форм; центрированную карточку со скроллом; адаптивность; переключатель темы; ресёрч и подключение иконок (если ресёрч подтвердит).
**Не делаем:** поведение/навигация; фоновое демо (08); игровое поле/Viewport (05); игровой UI (07); сеть (10).

## Открытые вопросы

- **Конкретные гайды** (HIG / Material / Fluent или сочетание) — уточняется ресёрчем на plan.
- **Иконочная библиотека** — выбор и обоснование (версии, лицензия, размер, tree-shaking); на plan.
- **Форма настроек темы** — сегментированный контрол, список или радиогруппа; деталь plan.
