# CONTEXT — Фаза 07: первая игра целиком (рендер, UI, против компьютера)

## Что делает фаза

Собирает крестики-нолики в цельную игру: рендер фигур на Viewport, Vue-UI игры,
запись в реестр и форма преднастройки, режим против компьютера. **Первый
щупабельный релиз.**

**Готово:** игра в списке; преднастройка запускает партию против компьютера; ходы
кликом; фигуры, линия победы и последний ход видны; баннер хода/результата;
игровое меню работает.

## Принятые решения

- **D1.** Vue-UI игры в `src/ui/games/<id>/`, реестр по id — архитектурный тест
  `architecture.test.ts:82-88` запрещает импорт `vue` под `src/games/**`.
- **D2.** `Session.draw(frame)` → `Game.draw(state, frame)` — игра stateless,
  состояние партии хранит `Session` (PROJECT.md:156, 228-234).
- **D3.** Выбор клетки через сервис `boardInput` — платформа не знает форму хода
  `{x,y}` (принцип 7a).
- **D4.** Преднастройка и запуск против компьютера через форму и
  `attachEnvironment`/лобби — образец `test-game/game.ts:171-207`, лобби готово
  (фаза 03).
- **D5.** `level` (0..4) объявлен в `getPropertySchema`; персистентность рейтинга
  (`game/<id>`) отложена в BACKLOG.
- **D6.** Конфетти и полировка вне фазы — BACKLOG:44, ROADMAP 11.

## Отклонённые варианты

- Vue-UI из записи игры — нарушает архитектурный тест (D1).
- Рендер без состояния — состояние у `Session` (D2).
- Платформа сама строит `{x,y}` — протечка формы хода в ядро (D3).
- Рейтинг в хранилище сейчас — не блокирует релиз (D5).
- Конфетти и анимации — полировка, BACKLOG (D6).

## Объём фазы

**Делаем:** контракт `Game.draw`/`Session.draw`; рендер фигур; токены
`--board-x`/`--board-o`; реестр игры и форма преднастройки; реестр UI игр и монтаж
в слой 2; UI игры (клик, баннер); сервис `boardInput`; режим против компьютера;
тесты и браузерная приёмка.

**Не делаем:** персистентность рейтинга (D5), конфетти/полировка (D6), демо (08),
хот-сит (09), сеть (10).
