# REPORT — Фаза 07: первая игра целиком

Статус: выполнен (авторежим, T1–T9). **Первый щупабельный релиз:** игра
запускается из меню и играется против компьютера.

## Что сделано

Крестики-нолики собраны в цельную игру: рендер фигур на Viewport
(`Session.draw` → `Game.draw(state, frame)`), Vue-UI игры (баннер хода/результата,
выбор клетки через сервис `boardInput`), запись в реестр, форма преднастройки
(режим + уровень ИИ), запуск против компьютера. Позже добавлен `ResultDialog.vue`
(итог + «Реванш»/«Выйти»).

## Файлы

- `src/core/game/render.ts` — `GameRenderFrame` (контракт отрисовки)
- `src/core/game/game.ts`, `index.ts` — базовый `Game.draw` (no-op), экспорт
- `src/core/session/session.ts` — `Session.draw(frame)`

- `src/games/tic-tac/game.ts` — `lastMove`/`winLine`; `draw`; форма, схема,
  `attachEnvironment`, запуск против компьютера
- `src/games/tic-tac/index.ts` — запись реестра игры
- `src/ui/board-input.ts` — сервис выбора клетки (мост слой 1 → UI игры)
- `src/main.ts` — provide `boardInput`
- `src/ui/shell/LayerBoard.vue` — Viewport + рендер активной игры + pick
- `src/ui/games/registry.ts`, `index.ts` — реестр «id игры → Vue-компонент»
- `src/ui/games/tic-tac/TicTacToeUi.vue`, `ResultDialog.vue` — UI игры
- `src/ui/shell/LayerGameUi.vue` — монтирование UI активной игры
- тесты `session.test.ts`, `tic-tac/game.test.ts`, `platform.test.ts`

## Найдено и исправлено в ходе исполнения

- **Перерисовка после хода не происходила.** `watch` в `LayerBoard` зависел от
  `sessionHost.session` (shallowRef), номер ревизии не реактивен: камни появлялись
  только после панорамирования/зума. Исправлено на
  `session.subscribe(() => viewport.draw())` (+ перерисовка при смене сессии).
  Найдено браузерной проверкой.

   уже имеет доступ к сессии; отдельный сервис не нужен.
3. **«Сдаться и выйти» показывается и против компьютера** (`players.length > 1`) —
