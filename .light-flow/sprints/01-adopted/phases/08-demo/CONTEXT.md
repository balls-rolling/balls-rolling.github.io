# CONTEXT — Фаза 08: фоновое демо

## Что делает фаза

На фоне приложения постоянно идёт живая партия случайной игры из реестра (ИИ vs
ИИ), поверх — главное меню. Демо — обычная сессия с параметром `demo`; флаг
`isDemo` ставит сессия, способ демо решает игра. На поле нет игрового UI.

**Готово:** за меню видна играющая партия (движение, не картинка); после окончания
демо продолжается новой партией; запуск реальной игры сменяет демо; в демо нет
баннера и игрового меню.

## Принятые решения

- **D1.** Состав демо объявляет игра: `Game.getDemoPlayers(): readonly PlayerInit[]
  | null` (по умолчанию `null`); платформа выбирает случайную запись с демо —
  PROJECT.md:174,180.
- **D2.** `Platform.createDemoSession()` перебирает реестр, поднимает игру,
  спрашивает `getDemoPlayers`, создаёт `Session` с `options.demo`, возвращает
  `Session | null` — выбор игры дело платформы (PROJECT.md:168).
- **D3.** Граница слоёв: поле и диалоги монтируются всегда, слой игрового UI — нет;
  меню — диалог поверх демо (PROJECT.md:17-18). Расхождение с буквой
  PROJECT.md:243-245 («слои 2 и 3») разрешено здесь: читаем как собственные
  UI/диалоги демо-игры.
- **D4.** Жизненный цикл: после партии composition root перезапускает сессию
  (`restart()`) через небольшую паузу — живой фон; пауза при скрытой вкладке в
  BACKLOG.
- **D5.** Демо крестиков-ноликов: два компьютера («Компьютер 1/2»), `level = 2`,
  `missWin = false` — партия должна завершаться (PROJECT.md:122-123).
- **D6.** Новых зависимостей нет — нативный код.

## Отклонённые варианты

- Платформа сама создаёт демо-игроков — решала бы способ демо за игру (D1).
- Логика демо в `main.ts` — место платформы, тестируемость (D2).
- Монтировать весь UI и прятать CSS — лишний DOM/инертность (D3).
- `missWin` обоим ИИ — партия может не завершиться (D5).
- Пауза по скрытой вкладке сейчас — хвост (D4).

## Объём фазы

**Делаем:** `Game.getDemoPlayers`; `Platform.createDemoSession`; запуск демо в
composition root + перезапуск; граница слоёв; состав демо крестиков-ноликов; тесты.

**Не делаем:** пауза/CPU-бюджет демо (BACKLOG), «нет естественного демо» (BACKLOG),
хот-сит (09), сеть (10).
