# PLAN — Фаза 09: локальный хот-сит

**Флаг тестов фазы:** y. **Статус:** выполнен — см. REPORT.md.

Цель: режим вдвоём за одним экраном — две локальные человеческие сессии, ход по
очереди, баннер с именем.

## Задачи

- **T1.** Кнопка «Двое за экраном» (`hotseat`, иконка `users`) в группе «Режим»
  формы преднастройки; группа остаётся вертикальной. `src/games/tic-tac/game.ts`.
  tests y.
- **T2.** Запуск двух локальных людей: `#start` принимает состав
  (`humans`/`computers`); подписка на `hotseat` зовёт `#start` с `{ humans: 2,
  computers: 0 }`, `vs-computer` — `{ humans: 1, computers: 1 }`.
  `src/games/tic-tac/game.ts`. tests y.
- **T3.** Тесты формы в `src/games/tic-tac/game.test.ts`: `hotseat` есть,
  `vs-computer` остаётся. tests y.
- **T4.** Проверка фазы: `npm test`, `npm run typecheck`, `npm run build`, браузер.
  tests y.

## Решения

| # | Решение | Обоснование | Отвергнуто |
| --- | --- | --- | --- |
| 1 | Хот-сит = 2 локальных человека | Очередь уже в сессии (D1) | Свой механизм хода |
| 2 | Модель игрока не меняем | agent/transport уже разделены; глиф — часть правил (D2) | Глиф в свойства |
| 3 | Баннер с именем | Уже есть (D3) | Экран передачи хода |

2. Браузер: «Двое за экраном»; два имени; ход чередуется кликами; баннер меняется;
