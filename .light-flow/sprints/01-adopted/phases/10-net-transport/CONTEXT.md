# CONTEXT — Фаза 10: сеть A (транспорт, протокол, ходы)

## Что делает фаза

Даёт платформе абстракцию канала `Transport` (локальный и WebRTC), протокол поверх
DataChannel и синхронизацию ходов для партии по сети через **ручной обмен кодом**,
без сигналинг-сервера. Плюс минимальный экран хост/гость для проверки на двух
вкладках.

**Готово:** хост создаёт приглашение, гость вставляет и получает ответ; партия идёт
на обоих концах (ходы, имена); локальная (хот-сит/ИИ/демо) партия без изменений.

## Принятые решения

- **D1. Разбиение:** фаза 10 — `Transport`+протокол+ходы+минимальный обмен кодами;
  фаза 11 — лобби, ссылка/QR, реванш/отключение; деплой сдвинут 11→12. Причина:
  объём >10 задач, подпапки ломают определение активной фазы (D12 фазы 03). Отклонено:
  одна большая фаза 10.
- **D2. `Transport` в ядре** (`send`, `onMessage`, `state`, `close`; реализации
  локальная и WebRTC). Причина: PROJECT.md:86-89,127-128,159. Отклонено: протокол
  прямо в сессии (протечка сети в ядро).
- **D3. WebRTC — порт `net/rtc.js`** (проверенное решение `net/rtc.js:1-125`);
  без trickle, мягкое ожидание ICE, ответ сразу после сбора ICE, STUN Google.
  Причина: PROJECT.md:124-127. Отклонено: свой сигналинг-сервер (противоречит
  статике github.io).
- **D4. Формат приглашения: SDP + метаданные** (id игры, версия протокола, роль,
  имя), base64url; структурная проверка при декоде; подписи нет (оффлайн, нет
  ключей). Причина: ответ пользователя; BACKLOG.md:9-11. Отклонено: только SDP;
  подпись.
- **D5. Синхронизация — ходы; host = игрок 1 (X), guest = игрок 2 (O)**; сообщения
  `hello`, `move ({x,y})`, `surrender`, `bye`; `rematch-*` — фаза 11. Причина: ответ
  пользователя; `net/protocol.js:1-32`. Отклонено: полный снимок состояния.
- **D6. Мост сети — в UI-адаптере, `Session` не знает про транспорт**; игроки
  `transport:"remote"` создаются на старте, их ходы из сети. Причина: PROJECT.md:
  127-128, принцип 7a. Отклонено: учить `Session` транспорту.
- **D7. Минимальный экран обмена кодом** (кнопки «Создать»/«Присоединиться», код +
  поле ответа). Причина: делает фазу проверяемой. Отклонено: всё лобби-UI в 10.
- **D8. `LocalTransport` — no-op-канал** для локальных партий (единый интерфейс и
  тесты). Причина: PROJECT.md:159. Отклонено: ветвление `if (isNetworked)` в игре.

## Отклонённые варианты

| Вариант | Почему отклонён |
| --- | --- |
| Одна фаза на всю сеть | >10 задач, трудно проверяемо (D1) |
| Сигналинг-сервер | Противоречит статике github.io (D3) |
| Приглашение из одного SDP | Нет метаданных и проверки (D4) |
| Полный снимок состояния | Тяжелее, менее детерминированно (D5) |
| Транспорт внутри `Session` | Смешение слоёв (D6) |
| Всё лобби-UI в фазе 10 | Раздувает фазу (D7) |

## Объём

**Делаем:** `Transport` (интерфейс + локальный + WebRTC), кодек приглашения с
метаданными, протокол (`hello/move/surrender/bye`), синхронизация ходов через мост
в UI, минимальный экран обмена кодом, тесты протокола/кодека/локального транспорта.

**Не делаем:** QR/ссылка, реванш, имена в лобби, полировка отключения (11); деплой (12).
