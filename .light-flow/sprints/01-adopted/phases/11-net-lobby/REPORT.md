## Сделано

Полноценное сетевое лобби вместо минимального обмена кодами: хост ведёт состав
(список, выгон), партия стартует **только по «Начать»**, у гостя — лобби ожидания
с выходом; приглашение **ссылкой** `?open=net_game&…` и **QR** (обе стороны),
deep-link с платформенным реестром `open`-обработчиков, реванш.

   а не уведомлением (уведомление — только если `open`-обработчик бросил: игра не

4. **Реванш** — упрощённо «первое согласие = перезапуск» (offer→auto-accept), без
   отдельного диалога у принимающей стороны.
5. **`kickable`/`CodeExchangeView`** — не понадобились; удалён.

## Правки по замечаниям пользователя (кратко)

- **QR — по кнопке, в отдельном диалоге** (`QrDialog.vue`), генер. при открытии;
  закрытие — флексовая кнопка внизу. То же для ответа.
- **Сжатие кода:** `encodeInvite`/`decodeInvite` стали асинхронными, сжимают JSON
  нативным `deflate-raw` (`CompressionStream`), префикс `z`/`u`. Код приглашения
  **783 → 560 симв.** (~28%). Тесты кодека и вызовы лобби обновлены.
- **Раскладка:** токен `--dialog-margin` (общий отступ); `ScreenSpec.wide` для
  QR-диалога; QR по центру `min(100%, 68vmin)`.
- **Кнопки:** классы `.btn--flex` (делит строку), `.btn--auto` (по содержимому),
  `.btn--block` (вся ширина), `.btn--sm`; `.btn--flex`/`.btn--auto` управляются
  явно. Флекс — из метаданных `Control.flex` (`undefined`/`true` — по группе,
  `false` — по содержимому, объект `{grow,shrink,basis}` — свои); `ControlHost`
  навешивает инлайн-стиль.
- **Вариант цвета — `Control.variant`** (`primary`/`secondary`/`ghost`/`danger`) →
  класс `btn--<variant>` (по умолчанию `secondary`); семантические токены темы.
- **Иконка `qr`** (`QrCode` из `@lucide/vue`); кнопка QR — иконкой, текст-фолбэк.
- **Подложка:** модальный диалог → затемнение + `blur(6px) saturate(.7)`; отдельного
  «только затемнение» нет (решение пользователя). Немодальный `<dialog>` поверх
  модального неинтерактивен (`inert`), поэтому QR-диалог модальный.
- **Причина бага флекса кнопки:** `.group--horizontal > *` и `.group > .btn
  {width:100%}` перебивали `.btn--auto`; правило сужено до вертикальных групп, для
  `.btn--auto` — исключение.
