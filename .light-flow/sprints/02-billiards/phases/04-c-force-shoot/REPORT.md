## Что сделано

- **T1 Порядок удара и сброс:** `BilliardsGame.resetRuntime()`; вызывается в
  `detachEnvironment`; `startShot` снимает прицел; при непринятом `makeMove`
  реплей сбрасывается. Удар — только кнопкой; канвас сам не стреляет.
- **T2 Сила:** слайдер 0..100 % и колесо на канвасе меняют силу (0..1).
- **T3 Кнопка удара:** «Удар» применяет удар текущими углом/силой; во время
  реплея заблокирована (и слайдер).
- **T4 Панели и инфо-бар:** состав игроков и текущий игрок из снимка сессии,
  обновляются по подписке; «Ходит: …».
- **T5 Снятие прицела и очистка моста:** прицел убирается при ударе; `LayerBoard`
  на dispose очищает `boardInput.canvas`/`requestDraw`.
- Тест ядра: `resetRuntime` сбрасывает анимацию/прицел/итог.

## Правки после verify (по репорту пользователя)

- **Баг: удар не делался.** Воспроизведено: кнопка «Удар» молчала, если до этого
  не навести мышь на стол (`aim === null` → удар не брался). Исправлено.
- **Уточнённая схема ввода (по требованию пользователя):** наведение —
  перетаскиванием: зажал указатель и ведёшь (`pointerdown` + `pointermove`,
  `setPointerCapture`), отпустил — наведение закончилось (`pointerup` только
  прекращает жест, **без выстрела**); удар — **только кнопкой** «Удар».
  Направление сохраняется после отпускания; кнопка без наведения бьёт по
  умолчанию в сторону пирамиды; `pointercancel` прекращает наведение без выстрела.
- Проверено в браузере: драг-наведение `revision` 1→1 (выстрела нет), затем
  «Удар» 1→2. `typecheck` 0, 358 тестов, `build` 0.

- **Баг 2 (по репорту «наведение не работает, кнопка неактивна»).** Причина: UI
  находил игру через `instanceof BilliardsGame`; после HMR модуль мог
  раздвоиться, `instanceof` давал ложный минус → UI терял игру (прицел мёртв,
  кнопка мертва). Исправлено: **структурная проверка** игры (наличие методов)
  вместо `instanceof`. Плюс добавлена защита от «залипшей» анимации: у
  воспроизведения появился кап по времени (`MAX_SHOT_SECONDS`), состояние
  `animating` сверяется с игрой — кнопка/прицел не замирают навсегда.
  Проверено на чистой перезагрузке: драг даёт `aim`, «Удар» — 1→2.
