# CONTEXT — Фаза 01 «Оживление удара» (спринт 03)

## О чём фаза

Диагностика и чинка двух подтверждённых живьём дефектов: прицел не
появляется после drag ([04b-F1]), кнопка «Удар» молча не срабатывает
([04b-F2], revision стоит, ошибок в консоли нет). Ядро в node исправно
(`startShot → makeMove` accepted, revision+1 — проверено временным зондом
на ревизии): рвётся обвязка UI/сессия живьём.

Done: drag рисует линию + кий; «Удар» двигает шары, revision растёт;
регрессионные тесты на оба дефекта зелёные; проверено интеракцией
(доверенный ввод) на свежем билде, непроверенное честно помечено.

Источники: кодовый путь — `BilliardsUi.vue:92-118` (`shoot`, `aimAt`),
`session.ts:233-255` (`makeMove`), `game.ts:95-103,176-184`
(`applyMove`/`parseShot`, `resetRuntime`); лиды ревизии — тихие выходы,
отклонённый ход + молчащий сброс, несвежая инстанция игры (`#lastState
null`); попутно `Viewport.vue:155,181` — capture без try/catch.

## Решения (с причинами)

- **D1. Только корень, без явной диагностики тихих выходов.** Решение
  пользователя. Причина: не раздувать фазу инфраструктурой; тишина —
  симптом, а не болезнь. Цена: следующий немой отказ снова придётся
  искать руками — принято осознанно.
- **D2. Объём минимальный, «шире» отменено.** Решение пользователя
  («отбой, оставляем как есть»): удар + прицел, регрессионные тесты, гарды
  capture в `Viewport`. Слайдер — фаза 02, раскладка — фаза 03, нормы R4 —
  фаза 03. Причина: держать фазу в пределах 10 задач и одного понятного
  результата.
- **D3. Без сплита.** Одна диагностика + чинка — один план.

## Отвергнутые варианты

- «Корень + диагностика тихих выходов» — отвергнуто пользователем (D1).
- «Шире: слайдер/раскладка/диагностика в фазу 01» — предложено к уточнению,
  отменено пользователем («отбой»).
- Переделка `host.game`/очереди ходов — не вариант вовсе: корень чиним
  точечно, архитектуру сессии не трогаем (may-break из обсуждения).

## Подразумеваемое (сказано неявно, зафиксировано)

- Проверка — доверенным вводом (настоящая мышь / devtools-click):
  синтетические PointerEvent'ы канвас-слушатели игнорируют молча
  (установлено на ревизии: событие доходит, прицела нет) — evidence только
  живое.
- Dev-серверы на старых билдах гасятся перед проверкой; порт — свободный
  (был конфликт :5173/5199 на ревизии).
- Регрессионные тесты минимум: прицел после drag, удар принят + revision,
  прицел гаснет на время удара (покрывает жалобу — verify-process п.4).

## Два списка

- **Forgot:** гарды `setPointerCapture`/`releasePointerCapture` в `Viewport`

  тихий `resetRuntime` при отклонённом ходе остаётся тихим (D1 — осознанно);
  скриншоты/замеры — артефакты фазы рядом с REPORT.
- **May break:** слайдер и сила (фаза 02) — не трогаем; платформа

  гарды capture; очередь ходов и `host.game` — не перепроектируем.
