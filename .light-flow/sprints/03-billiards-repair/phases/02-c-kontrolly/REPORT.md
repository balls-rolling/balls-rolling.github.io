# REPORT — Подфаза 02-c «Контроллы»

Статус: execute выполнен, ждёт verify. Тесты фазы: y + живьём.

## Что сделано

- **T1. Глобальные селекторы.** `base.css`: `input[type="range"]` исключён из
  правил «поля ввода» (`input:not([type="range"])`) — больше не наследует
  `cursor:text`, `user-select:text`, фон/рамку/паддинги/min-height. Правка в
  источнике, без точечных исключений.
- **T2. Стилизация range.** `appearance:none` + свой трек (6px, скруглённый) и
  бегунок (18px, `--accent-grad`), `cursor:pointer`, `user-select:none`, без
  боксовой геометрии текстового поля. Бегунок доходит до края.
- **T3. Значение.** `.billiards-ui__power-value`: `tabular-nums`, `min-width:4ch`
  — панель не дёргается на 0→100%.
- **T4. Панель не на сукне.** `computeFit(size, padding, bottomInset)`; у игры —
  рантайм-слот `#bottomInset` (`setBottomInset/getBottomInset`); UI измеряет
  высоту панели (`ResizeObserver`) и задаёт отступ; `draw`, `worldFromEvent`,
  `angleFromEvent` используют один и тот же отступ.
- **T5. Шкала тонкого поворота.** `.billiards-ui__angle` — горизонтальная лента
  тиков рядом с силой, риска по центру (`__angle-mark`); тики — повторяющийся
  градиент, сдвигается `background-position-x` от текущего угла; перетаскивание
  крутит угол на `dx / ANGLE_SCALE_PX_PER_DEG` (2 px/град), бесконечно, с
  бесшовным wrap через `wrap360`.
- **T6. Живая перепроверка 04-c** новым баром (см. Conformance).
- **T7. Контур:** `typecheck` 0, бильярд 92/92, полный 373/373, `build` 0.

## Правки по замечаниям (повторная проверка)

- **Чувствительность шкалы:** 2 px/град → **1 px/град** (замечание «слишком
  чувствительная»). Живьём: +60px → +60°.
- **Число силы без дёрганья:** значение перенесено **над ползунком**, по центру,
  фиксированной ширины (220px, как трек) → ширина и центр не меняются на
  0/50/100 (замер: 220.00, cx 499.0); для «число растёт с ростом» — размер
  шрифта 0.95→1.05em (замер: 16px → 16.8px).
- **Скачок масштаба при ударе (баг):** ветка реплея `BilliardsGame.draw`
  рисовала `drawBilliards(runtime, frame, { aim: null })` **без** `bottomInset` —
  на время анимации стол вписывался без запаса (крупнее) и панель его
  перекрывала; после покоя возвращался. Исправлено: ветка реплея передаёт
  `bottomInset`. Живьём: нижняя кромка рейки на покое и во время реплея
  совпадает (867 в 7 замерах подряд).

## Правки по замечаниям (третья проверка)

- **Фон вокруг стола:** был в тон сукну (сливался) → отдельный тёмный
  `BACKDROP_COLOR = #0b0f10` (`constants.ts`, `render.ts`). Живьём: угол кадра
  `[11,15,16]`.
- **Сетка/отступы:** единый базовый отступ стола `FIT_PADDING = 24` (экспорт
  `render.ts`), используется и рендером, и координатами ввода. Живьём: отступ
  слева/справа по 24px, стол не касается краёв, панель ниже стола.
- **Ползунок силы — кастомный контролл** (нативный `range` убран): широкий
  скруглённый трек, круглая каретка с числом; заливка — градиент
  `transparent → зелёный (25%) → красный`, `linear-gradient(in oklch …)`;
  цвет каретки и текста — от значения (`powerColors`, oklch; тёмный текст на
  зелёном, белый на красном); размер числа растёт 0.90→1.10em; каретка не
  выходит за края. Клавиатура: стрелки/Shift/Home/End, `role="slider"`.
  Живьём: 0% — `oklch(0.72 0.17 150 / 0.15)`, 25% — `oklch(0.72 0.17 150)`,
  100% — `oklch(0.7 0.2 25)`.
- **`base.css` возвращён к исходному виду:** нативного `range` в проекте больше
  нет, правки селекторов стали мёртвыми; K1–K3 снимаются самим контроллом
  (кастомный ползунок — не поле ввода).

## Правки по замечаниям (четвёртая проверка)

- **Один ход вместо трёх.** В UI бильярда было три места про ход («Игрок» в ряду
  игроков, «Ходит: Игрок» в инфо и сессионный бар платформы). Дубли убраны
  (`.billiards-ui__players` и `.billiards-ui__info` удалены), осталась **одна
  заметная плашка** `.billiards-ui__turn`: акцентная заливка, `--fs-lg`,
  скругление. Живьём: фон плашки — акцент, кегль 20px. (Карточки игроков со
  шкалами забитых шаров — по словам пользователя, позже.)
- **Сессионный бар платформы** («running · ходит X · revision N») не тронут — это
  общий слой (`SessionHost.vue`) и предмет фазы 03 (K4/M4). Отмечено в «Открыто».
- **Заливка шкалы — цельным цветом, не градиентом.** `.billiards-ui__power-fill`
  теперь сплошной цвет по значению (`powerFillColor`): прозрачный→зелёный
  (первая четверть), затем зелёный→красный. Живьём: `background-image: none`;
  10% → `oklch(0.72 0.17 150 / 0.49)`, 60% → `oklch(0.7 0.2 91.7)`.
- **Цвет числа, а не каретки.** Каретка — нейтральный фон (`--surface-2` + рамка),
  меняется **цвет текста** (`powerTextColor`). Живьём: фон `rgba(20,28,38,.92)`
  постоянен; текст 10% → `oklch(0.75 0.068 150)`, 60% → `oklch(0.62 0.19 91.7)`.
- **Шаг значения 1.** Колесо и стрелки клавиатуры: шаг 1 (Shift — 10), перетаскивание
  округляет до целого. Живьём: колесо 60 → 61 → 60.

  только для тонкой доводки. Ждёт живого подтверждения ощущения (шкала бесконечная,
  так что точная доводка возможна, но длинным жестом).
