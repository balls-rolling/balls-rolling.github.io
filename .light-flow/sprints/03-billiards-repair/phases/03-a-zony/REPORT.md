## Что сделано

- **T1. Ядро зон** (`src/core/ui-zones/`): `ZoneName` (top/bottom/left/right),
  `ZoneSchema { orientation?, nodes }`, `UiLayoutSchema`, `createUiZones` →
  `{ zones, zone(name), handle }`. Состояние и сигналы всех зон — один
  `createFormController` по узлам (`FormNode`), второй системы не завели;
  направление по умолчанию: верх/низ — горизонтально, лево/право — вертикально.
- **T2. Контракт:** `Game.getUiLayout()` (дефолт `{ zones: {} }`);
  `GameEnvironment.game.ui: UiZones`; `createGameEnvironment` принимает `ui`.
- **T3. Рендер и слот:** `src/ui/ui-zones/` — `slot.ts` (слот зон, destroys
  прошлый хендл), `ZoneHost.vue`, `Zones.vue` (сетка 4 зон, рендер узлов
  существующим `FormView`/реестром контроллов); `main.ts` создаёт слот;
  `SetupScreen` создаёт зоны из `getUiLayout()`, кладёт в слот и отдаёт в
  окружение; `LayerGameUi` монтирует `Zones` и очищает слот, когда сессия
  ушла (партия не переживает зоны). **Потребитель для проверки** — тестовая
  игра: `getUiLayout()` с верхней зоной (кнопка-сигнал + подпись).
- **T4. Опт-аут панели:** `GameViewOptions.playersPanel?` (дефолт `true`),
  бильярд — `false`; `SessionHost` показывает ход только если игра не отказалась.
- **T5. Чистка прод-UI (K4/M4):** из `SessionHost` убраны `state` («running») и
  `revision`; меню (`GameMenu`) — первым (влево); ход — справа от меню.
- **T6. Контур:** typecheck 0, 378/378, build 0, architecture 5/5.
  Живой просмотр и регрессия крестиков — за человеком (браузерных инструментов
  в сессии нет).
